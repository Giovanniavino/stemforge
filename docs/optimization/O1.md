# O1 — CPU del motore fuori dal modello

Agente O1, Fase 3. Area: `engine/` e `worker/pipeline.py`, `passes.py`,
`assemble.py`. Regole: BUILD_SPEC §6, §6.2, §11 regola 12 e il registro
generale [OPTIMIZATION_LOG.md](../OPTIMIZATION_LOG.md).

## Macchina e metodo

- Dev-box: AMD Ryzen 5 5625U, 6 core fisici / 12 logici, Windows 11,
  `device=cpu`. Altri agenti girano in parallelo: le misure sono
  **alternate A B A B** (processi separati, stesso file d'ingresso) e si
  legge il **tempo CPU del processo** (`time.process_time`) e il **picco
  della memoria privata** (`PeakPagefileUsage` di `K32GetProcessMemoryInfo`)
  meno quella dopo gli import.
- A = `integrate/v3` (2f7e3be) estratto con `git archive`, B = questo
  branch. Mediana di 5 ripetizioni per lato.
- Caso riproducibile generato in codice: 180 s stereo, sinusoidi 220/330 Hz
  + rumore gaussiano 0.05 (seed 1234), WAV PCM_24 a 48000 Hz (il caso
  comune: resampling in ingresso e in uscita) e a 44100 Hz.
- Pipeline completa (`worker.runner.run_job`: decodifica, resampling,
  blocchi, overlap-add, assemblaggio, scrittura, manifest) con un backend
  finto che restituisce `audio * coeff` per sorgente: tutto ciò che sta
  FUORI dal modello, senza il rumore dell'inferenza. Job: vocals, drums,
  bass, other, `balanced`, WAV.
- Identità: SHA-256 dei byte di tutti gli stem scritti, uguale fra A e B.

Comando (lo script sta nello scratchpad dell'agente, qui la sostanza):

```text
python ab.py 5 <src A> <src B> -- 180 48000 wav
  ab.py     : per i in 1..5, per src in (A, B): subprocess harness.py con PYTHONPATH=src
  harness.py: genera il WAV se manca, importa torch/torchaudio, poi misura
              process_time + perf_counter + PeakPagefileUsage attorno a run_job
```

## Profilo di partenza (cProfile, 48 kHz, 180 s, 4 stem, A)

Tempo di parete 5.6 s, CPU 8.5 s (il resampling è multithread).

| Voce | cumulativo | nota |
|---|---|---|
| `folder.write_stem` ×4 | 3.26 s | `sf.write` 2.29 s (conversione float→PCM_24 di libsndfile 1.58 s, trasposizione `audio.T` in soundfile ~0.09 s/stem), `rms_dbfs` 0.73 s (quadrato in float64), `peak_dbfs` 0.24 s |
| `audio_io.resample` ×5 | 1.42 s | 1 in ingresso + 4 in uscita: **la voce del 1° stadio si riporta a 48 kHz due volte** (stem `vocals` e termine della sottrazione di `other`) |
| `audio_io.load` | 0.31 s | decodifica soundfile 0.16 s |
| `run_pass_blocks` | 0.27 s | overlap-add 0.14 s (blocco unico: una copia) |
| `sha1_of` sorgente | 0.06 s | |

Picco della memoria privata oltre gli import: 1115 MB a 48 kHz, 469 MB a
44.1 kHz (a 44.1 kHz il ritorno al sample rate originale non copia).
